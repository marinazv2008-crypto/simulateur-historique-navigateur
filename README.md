# Simulateur d'historique de navigation

Projet réalisé en NSI en Terminale.

Ce programme simule l'historique d'un navigateur web en utilisant
des piles (`deque`).

Fonctionnalités :
- reculer dans l'historique ;
- avancer dans l'historique ;
- visiter une nouvelle URL ;
- gérer plusieurs onglets avec une classe `Historique`.
